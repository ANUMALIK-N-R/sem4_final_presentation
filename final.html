02
The Challenge
Problem Statement

Malayalam speech presents unique challenges that make automated transcription far harder than English.

Language Complexity
Malayalam has diverse dialects, agglutinative morphology, and rapid speech with complex phonetic characteristics.
Long-form Audio
Meeting recordings run 30–60 minutes. Naive Whisper hallucinates beyond 30s without smart chunking.
Real-world Audio Quality
Background noise, overlapping speakers, varying mic distances degrade transcription.
Meeting Context
Minutes need structure, attribution, decisions, action items — not raw text.
03
What Didn't Work
Experimental Failures

Before final pipeline, many naive approaches were tested & systematically rejected.

  • Full-Audio Processing — Whisper hallucinations & looping repetitions beyond 30s.
  • Fixed-Length Chunking — Split sentences mid-word, broke linguistic context.
  • Aggressive Silence Detection — Cut words mid-pronunciation, treated consonants as silence.
  • Generic Multilingual Whisper — Confused Malayalam with Tamil/Telugu, lacked vocabulary.
Lesson learned: Language-specific preprocessing & model selection are not optional — they define usability.

Module 1
AudioPreprocessor

Converts any audio input into clean 16 kHz mono WAV — the exact format Whisper expects.

1
Multi-format Loading
PyDub reads MP3, WAV, M4A automatically. No manual conversion needed.
2
Stereo → Mono + Resample
Collapses channels & resamples to 16,000 Hz (Whisper requirement).
3
Peak Normalization
samples / (max_abs + 1e-8) ensures consistent loudness across recordings.
# Load any format via PyDub
audio = AudioSegment.from_file(audio_path)
audio = audio.set_channels(1).set_frame_rate(16000)
# Export to temp file, load as numpy
samples, _ = librosa.load(tmp_path, sr=16000, mono=True)
samples = samples / (np.max(np.abs(samples)) + 1e-8)
06
Module 2
DiarizationEngine

Answers "who spoke when" using neural speaker embeddings & unsupervised clustering.

VAD + Smart Merging
split_on_silence (min_silence=600ms, -40dB) and greedy merge up to 25s/segment — gives Whisper enough context without hitting 30s attention limit.
ECAPA-TDNN Embeddings
SpeechBrain’s spkrec-ecapa-voxceleb encodes each segment into 192-dim speaker fingerprint.
Agglomerative Clustering
L2-normalized embeddings clustered. Silhouette scoring auto-selects best k (2–6 speakers). Labels: Speaker_A, Speaker_B, etc.
Auto Speaker Count
No manual input required — silhouette score picks optimal clusters dynamically.
07
Module 3
MalayalamTranscriber

Converts each diarized audio segment into Malayalam text using a fine-tuned Whisper model.

Model: thennal/whisper-medium-ml
769M parameters, fine-tuned on Malayalam corpus. Vastly outperforms generic multilingual Whisper on agglutinative forms and regional accents.
Forced Decoder IDs
Language locked to "ml" (ISO 639-1), task "transcribe" — prevents switching to English/Tamil mid-output.
# Force Malayalam transcription mode
forced_ids = processor.get_decoder_prompt_ids(
language="ml", task="transcribe")
# Extract mel features & generate
inputs = processor(chunk, sampling_rate=16000, return_tensors="pt")
ids = model.generate(inputs.input_features, forced_decoder_ids=forced_ids)
text = processor.batch_decode(ids, skip_special_tokens=True)[0]

Engineering Depth
Key Design Decisions
CUDA-aware Inference
All models move to GPU automatically → reduces transcription time from minutes to seconds per segment.
Auto Speaker Detection
Silhouette score selects best k from 2–6, no manual input.
25-Second Merge Limit
Balances context richness vs Whisper’s 30s attention limit — critical to avoid hallucinations.
Epsilon Normalization
samples / (max + 1e-8) guards division-by-zero on silent recordings.
Modular Class Design
Each class has single responsibility; swap diarizer or LLM without breaking orchestrator.
Temp File Strategy
Normalized audio reused by diarizer & transcriber — minimal I/O overhead.
